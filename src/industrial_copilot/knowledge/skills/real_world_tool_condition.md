## Real-world context
Real milling tool-condition monitoring can use richer signals than AI4I, including controller data, acceleration, audio and vibration. This is useful for explaining which additional evidence could improve a production deployment.

## Safe use
This reference cannot prove that a specific AI4I incident was caused by tool wear or vibration. Use it only to identify missing evidence and cautious inspection context.
