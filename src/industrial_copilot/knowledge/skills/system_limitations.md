## Available data
The project has AI4I observations, calculated engineering features, calibrated local model risk, disclosed simulated scenarios and AI4I replay.

## Unavailable data and actions
The project has no live PLC/SCADA feed, timestamped plant history, vibration, audio, repair history, CMMS connection, remaining-useful-life model or machine-command capability.

## Safety boundary
The system is decision support. Retrieved knowledge cannot change safety limits, select tools, issue actions or override deterministic evidence.
